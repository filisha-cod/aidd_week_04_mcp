# make_report

Детерминированный отчёт по задачам в Excel — формат задания 1.1 (`HOMEWORK.md`, `report_format.txt`).

## Когда применять
Нужен Excel-отчёт по задачам: сводные метрики, детальный перечень и разбивка по дедлайнам, причём одинаковый от прогона к прогону. Не считайте цифры по UI вручную и не собирайте отчёт «с нуля» — запустите скрипт ниже: он читает `apps\todo_db.json` и считает все цифры по тем же правилам, что и `report_format.txt`.

## Данные
- Источник: `apps\todo_db.json` → поле `payload.tasks`. Поля задачи: `id`, `title`, `done` (true/false), `priority` (low|normal|high), `due` (YYYY-MM-DD или null), `created_at` (YYYY-MM-DDTHH:MM:SS).
- «Сегодня» — системная дата на момент запуска. Она фиксируется в отчёте, поэтому формулы СЕГОДНЯ() в файл не попадают и прогоны в один день совпадают.

## Запуск
Из `practice\agent`:
```bash
python .qwen\skills\make_report\make_report.py
```

## Результат
- Файл: `practice\agent\report_ДД.ММ.ГГГГ.xlsx` (рядом с `report_format.txt`).
- Листы: «Сводка» (8 метрик + разбивка по приоритетам), «Задачи» (одна строка на задачу, сортировка «не выполненные → приоритет → дедлайн»), «Дедлайны» (группы по дедлайну × выполнение).

## Проверка
1. Открыть файл: ИТОГО по «Дедлайнам» должен равняться «Всего задач» на «Сводке» (30/14/16 для текущей БД), значения всех трёх листов согласованы.
2. Тесты: `cd .qwen\skills\make_report && python -m unittest make_report_test -v`.
3. Сверить метрики с данными в `apps\todo_db.json` при необходимости.
