ФОРМАТ ОТЧЁТА ПО ЗАДАЧАМ (итоговый файл — .xlsx)
Техническое задание 1.1 (HOMEWORK.md, раздел 1)
==============================================================

0. ИСТОЧНИК ДАННЫХ
------------------
- Файл: apps\todo_db.json (JSON с HMAC-подписью).
- Используются только данные payload.tasks — массив задач. Поле "sig"
  при вычислениях не используется.
- Поля одной задачи:
    id         int    уникальный идентификатор
    title      str    название
    done       bool   true = выполнена, false = не выполнена
    priority   "low" | "normal" | "high"
    due        "YYYY-MM-DD" | null    дедлайн (null = дедлайна нет)
    created_at "YYYY-MM-DDTHH:MM:SS"  дата и время создания
- "Сегодня" = системная дата на момент генерации отчёта (далее — «сегодня»).
  Все вычисления «от сегодня» (просрочка, «осталось дней», возраст, группы
  дедлайна) выполняются относительно неё, один раз при генерации отчёта.
- Даты: due — уже дата ("YYYY-MM-DD"); created_at — берётся только часть
  даты (время отбрасывается). null в due → пустая ячейка Excel.

1. СТРУКТУРА ФАЙЛА
------------------
- Имя: report_ДД.ММ.ГГГГ.xlsx (ДД.ММ.ГГГГ — дата генерации).
- Листов: 3 (требуемых минимум два выполнены), имена строго:
    1) «Сводка»  2) «Задачи»  3) «Дедлайны»
  Каждый лист несёт отдельную функцию: сводные метрики / детальный перечень /
  разбивка по дедлайнам. Порядок листов: Сводка → Задачи → Дедлайны.
- Тексты заголовков фиксированы (для сравнимости отчёта от прогона к прогону):
  «Всего задач», «Выполнено», «Не выполнено», «% выполнения», «Просрочено»,
  «Скоро (≤ 7 дней)», «Без дедлайна», «Высокий приоритет, не выполнено»,
  «По приоритетам», «Приоритет», «Всего», «Выполнено», «Не выполнено»,
  «Срок», «Статус дедлайна», «Группа дедлайна» и т.д. — см. раскладки ниже.

2. ЛИСТ «СВОДКА» — агрегаты
----------------------------
Раскладка (A1-нотация):
  A1        «ОТЧЁТ ПО ЗАДАЧАМ» (заголовок, жирный)
  A2        «Дата формирования: ДД.ММ.ГГГГ» — дата генерации, статичное значение
  A4:B4     заголовки: «Метрика» | «Значение» (жирные)
  A5:B12    восемь метрик (значения в B, расчёт в 2.1)
  A14:E14   заголовки таблицы «По приоритетам»:
            «Приоритет» | «Всего» | «Выполнено» | «Не выполнено» | «% выполнения»
  A15:A17   строки «Высокий», «Обычный», «Низкий»
  A18       «ИТОГО» (жирный)

2.1. Метрики (лист «Сводка»)
----------------------------
(1) Всего задач — общее количество задач в БД (любая done/priority/due).
    Excel: =COUNT(Задачи!A:A)
(2) Выполнено — задачи с done = true.
    Excel: =COUNTIF(Задачи!C:C,"Выполнена")
(3) Не выполнено — задачи с done = false.
    Excel: =COUNTIF(Задачи!C:C,"Не выполнена")
    Контроль: (2) + (3) = (1).
(4) % выполнения = (2) / (1) × 100, округление до 1 знака после запятой.
    Excel: =ROUND(B6/B5*100,1)
(5) Просрочено — НЕ выполненные задачи с дедлайном раньше сегодня
    (due < «сегодня»); бездедлайнные и будущие дедлайны не считаются.
    Excel: =COUNTIFS(Задачи!C:C,"Не выполнена",Задачи!F:F,"<"&TODAY())
(6) Скоро (≤ 7 дней) — НЕ выполненные с дедлайном в диапазоне
    [сегодня; сегодня+7] включительно.
    Excel: =COUNTIFS(Задачи!C:C,"Не выполнена",Задачи!F:F,">="&TODAY(),Задачи!F:F,"<="&TODAY()+7)
(7) Без дедлайна — НЕ выполненные с пустым дедлайном (due = null).
    Excel: =COUNTIFS(Задачи!C:C,"Не выполнена",Задачи!F:F,"")
(8) Высокий приоритет, не выполнено — НЕ выполненные с priority = "high".
    Excel: =COUNTIFS(Задачи!D:D,"Высокий",Задачи!C:C,"Не выполнена")

2.2. Таблица «По приоритетам» (A14:E18)
---------------------------------------
Для строки приоритета P (r = 15..17), текст P в столбце D листа «Задачи»:
  low→«Низкий», normal→«Обычный», high→«Высокий» (см. 3.2).
  B{r} Всего        =COUNTIF(Задачи!D:D,"<текст P>")
  C{r} Выполнено    =COUNTIFS(Задачи!D:D,"<текст P>",Задачи!C:C,"Выполнена")
  D{r} Не выполнено =B{r}-C{r}
  E{r} % выполнения =IF(B{r}=0,0,ROUND(C{r}/B{r}*100,1))
ИТОГО (строка 18): B18=SUM(B15:B17), C18=SUM(C15:C17), D18=SUM(D15:D17),
                    E18=IF(B18=0,0,ROUND(C18/B18*100,1)).
Контроль: B18=(1), C18=(2), D18=(3).

2.3. Форматы чисел
------------------
  B5:B7, B9:B12        целые (формат 0)
  B8, E15:E18          число с 1 знаком после запятой (0,0)
  F, I на листе «Задачи» — формат даты; G, J — целые; E — целое.

3. ЛИСТ «ЗАДАЧИ» — детальный перечень
--------------------------------------
По одной строке на задачу: заголовки в строке 1, данные с строки 2.
  A «ID» | B «Задача» | C «Статус» | D «Приоритет» | E «Ранг» |
  F «Дедлайн» | G «Осталось дней» | H «Статус дедлайна» | I «Создана» | J «Возраст, дн.»

Заполнение строки r для задачи t:
  A{r} = id (число)
  B{r} = title (текст)
  C{r} = "Выполнена" при done=true, иначе "Не выполнена"
  D{r} = «Высокий»/«Обычный»/«Низкий» по priority:
         high→«Высокий», normal→«Обычный», low→«Низкий»
  E{r} = 1 / 2 / 3 (low / normal / high) — число; служит для сортировки
  F{r} = дата из due; due=null → ячейка ПУСТАЯ (не текст "null" и не «—»)
  G{r} = для не выполненных С дедлайном: due − «сегодня» (целое; отрицательное
         значение = просрочка в днях); для выполненных и бездедлайенных — пусто.
         Excel: =IF(OR(C{r}="Выполнена",F{r}=""),"",F{r}-TODAY())
  H{r} = «Статус дедлайна» по правилам 3.1
  I{r} = дата из created_at (время отбрасывается)
  J{r} = «сегодня» − I{r} (целое). Excel: =TODAY()-I{r}

3.1. «Статус дедлайна» (колонка H)
-----------------------------------
Выполненные (done=true) → «Выполнена».
Не выполненные:
  due пустой                      → «Нет дедлайна»
  due < «сегодня»                 → «Просрочена»
  сегодня <= due <= сегодня+7    → «Скоро»
  иначе (due > сегодня+7)         → «В срок»

3.2. Сортировка строк (лист «Задачи»)
--------------------------------------
Четыре ключа (в Excel: Данные → Сортировка; для статуса — пользовательский
список «Не выполнена,Выполнена», а не алфавитный порядок):
  1) C: «Не выполнена» раньше «Выполнена»;
  2) E: 1 (Высокий) → 2 (Обычный) → 3 (Низкий);
  3) F: по возрастанию, пустые дедлайны — в конец;
  4) A: по возрастанию (при полном равенстве предыдущих ключей).
Эквивалент на Python (порядок тот же):
  rows.sort(key=lambda r: (r[2] != "Не выполнена", r[4], r[5] is None,
                           r[5] or date.min, r[0]))

4. ЛИСТ «ДЕДЛАЙНЫ» — разбивка по группам дедлайна
-------------------------------------------------
Таблица: заголовки в строке 1, данные с строки 2.
  A1 «Группа дедлайна» | B1 «Всего» | C1 «Выполнено» | D1 «Не выполнено»
  A2 «Просрочено» | A3 «Скоро (≤ 7 дней)» | A4 «В срок» | A5 «Нет дедлайна»
  A6 «ИТОГО» (жирный)

4.1. Группы (каждая задача попадает ровно в одну)
---------------------------------------------------
  «Просрочено»        : due < «сегодня» (любой статус)
  «Скоро (≤ 7 дней)»  : «сегодня» <= due <= «сегодня» + 7
  «В срок»            : due > «сегодня» + 7
  «Нет дедлайна»      : due пустой
Группы взаимоисключающие и покрывают все задачи, включая выполненные.

4.2. Расчёт (строка r = 2..5)
------------------------------
«Просрочено» (r=2):
  B2 =COUNTIF(Задачи!F:F,"<"&TODAY())
  C2 =COUNTIFS(Задачи!F:F,"<"&TODAY(),Задачи!C:C,"Выполнена")
  D2 =B2-C2
«Скоро (≤ 7 дней)» (r=3):
  B3 =COUNTIFS(Задачи!F:F,">="&TODAY(),Задачи!F:F,"<="&TODAY()+7)
  C3 =COUNTIFS(Задачи!F:F,">="&TODAY(),Задачи!F:F,"<="&TODAY()+7,Задачи!C:C,"Выполнена")
  D3 =B3-C3
«В срок» (r=4):
  B4 =COUNTIF(Задачи!F:F,">"&TODAY()+7)
  C4 =COUNTIFS(Задачи!F:F,">"&TODAY()+7,Задачи!C:C,"Выполнена")
  D4 =B4-C4
«Нет дедлайна» (r=5):
  B5 =COUNTIF(Задачи!F:F,"")
  C5 =COUNTIFS(Задачи!F:F,"",Задачи!C:C,"Выполнена")
  D5 =B5-C5
«ИТОГО» (r=6):
  B6 =SUM(B2:B5)    C6 =SUM(C2:C5)    D6 =SUM(D2:D5)

4.3. Проверки согласованности
------------------------------
  B6 = значение (1) листа «Сводка»;  C6 = (2);  D6 = (3).
  При расхождении — ошибка в формулах или в дате «сегодня».

4.4. Примечание
--------------
  Ячейка «Просрочено × Выполнено» — число выполненных задач, чей дедлайн
  наступил раньше сегодня. Отдельной даты выполнения в БД нет; ячейка
  фиксирует только пересечение фактов (done=true, due<сегодня) и не
  утверждает, что задача была выполнена после дедлайна.
